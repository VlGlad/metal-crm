# Контроллеры API

При добавлении нового API-эндпоинта в `app/src/Controller` создавай папку по предметной области или используй уже существующую. Например, для обновления заказа подойдёт `ProductionOrder` или `Order`. В этой папке создавай отдельный контроллер с методом `__invoke`, который отвечает только за этот эндпоинт и его функциональность.
